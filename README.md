# PIZZERIA
- En este documento se halla la especificación del desarrollo de la base de datos realizada para una Pizzeria que se encuentra con la necesidad de la creación de un sistema eficiente y centralizado para organizar, analizar y utilizar datos del negocio. Entre los problemas más destacados son sobre el gestionamiento deficiente para los clientes y repuestos, ineficiencia en la cadena de suministro y dificultades en el análisis de ventas y compras.

- Aquí se muestra de forma esquematizada la creación de una base de datos que solucione los problemas previamente mencionados para un gestionamiento de la información, almacenamiento y manipulación de datos eficiente y asequible para la empresa. Para lograr esto se realizaron los tipos de modelos necesarios para la base de datos, modelo conceptual, lógico y físico.
